أيوه، طبعًا.
سأشرحها لك بشكل عملي وبسيط، خصوصًا **الأوامر الأساسية في Obsidian** التي تحتاجها في البداية.

## أولًا: ما هو المقصود بـ "أوامر"؟

في Obsidian يوجد نوعان مهمان:

1. **أوامر الكتابة داخل الملف**
   مثل: العناوين، الروابط، القوائم، الصور، الجداول.

2. **أوامر البرنامج نفسه**
   مثل: إنشاء ملف جديد، البحث، فتح Command Palette، التنقل بين الملفات.

---

# 1) أهم أوامر البرنامج الأساسية

## فتح لوحة الأوامر

هذه من أهم الأشياء في Obsidian:

* **Ctrl + P**

تفتح لك **Command Palette**
ومنها تقدر تكتب اسم أي أمر وتنفذه.

مثلاً تكتب:

* New note
* Toggle preview
* Delete file
* Open settings

---

## إنشاء ملف جديد

* **Ctrl + N**

ينشئ Note جديدة.

---

## البحث داخل الفولت

* **Ctrl + Shift + F**

يبحث في كل الملفات داخل الـ Vault.

---

## البحث السريع عن ملف

* **Ctrl + O**

يفتح Quick Switcher
وتكتب اسم الملف فيفتحه بسرعة.

---

## حفظ

عادة Obsidian يحفظ تلقائيًا، فلا تحتاج Ctrl+S كثيرًا.

---

## فتح الإعدادات

* **Ctrl + ,**

---

## الرجوع والتقدم

مثل المتصفح:

* **Alt + Left Arrow** = رجوع
* **Alt + Right Arrow** = تقدم

---

# 2) أوامر الكتابة الأساسية داخل الملاحظات

Obsidian يعتمد على **Markdown**، وهي طريقة بسيطة لتنسيق النص.

## العنوان

تضع `#` قبل الكلام:

```markdown
# عنوان رئيسي
## عنوان فرعي
### عنوان أصغر
```

مثال:

```markdown
# مشروع الطائرة
## قسم المحرك
### ملاحظات السرعة
```

---

## كتابة عريضة أو مائلة

### عريض

```markdown
**نص عريض**
```

### مائل

```markdown
*نص مائل*
```

### عريض ومائل

```markdown
***نص***
```

---

## القوائم

### قائمة نقطية

```markdown
- عنصر أول
- عنصر ثاني
- عنصر ثالث
```

### قائمة مرقمة

```markdown
1. أول نقطة
2. ثاني نقطة
3. ثالث نقطة
```

### Checkbox

مفيدة للمهام:

```markdown
- [ ] مهمة لم تنته
- [x] مهمة انتهت
```

---

# 3) الروابط الداخلية بين الملفات

هذه من أقوى ميزات Obsidian.

## ربط ملف بملف

تكتب:

```markdown
[[اسم الملف]]
```

مثال:

```markdown
[[مشروع الطائرة]]
```

لو الملف غير موجود، Obsidian يمكنه إنشاؤه لك.

---

## ربط بعنوان مختلف

```markdown
[[اسم الملف|الاسم الذي يظهر]]
```

مثال:

```markdown
[[مشروع الطائرة|تفاصيل المشروع]]
```

---

## ربط عنوان داخل نفس الملف

لو عندك عنوان مثل:

```markdown
## النتائج
```

يمكنك الربط إليه هكذا:

```markdown
[[اسم الملف#النتائج]]
```

---

# 4) الوسوم Tags

تكتب:

```markdown
#مشروع
#الكترونيات
#بحث
```

مثال:

```markdown
هذا الملف يتعلق بـ #kicad و #pcb
```

تفيدك في تنظيم الملاحظات.

---

# 5) إدراج صورة أو ملف

لو عندك صورة داخل الفولت:

```markdown
![[image.png]]
```

ولو ملف PDF مثلًا:

```markdown
![[file.pdf]]
```

# 12) أوامر ستحتاجها كثيرًا في البداية

أنصحك تحفظ هذه أولًا فقط:

* **Ctrl + P** → لوحة الأوامر
* **Ctrl + N** → ملف جديد
* **Ctrl + O** → فتح ملف بسرعة
* **Ctrl + Shift + F** → بحث داخل الفولت
* **Ctrl + ,** → الإعدادات
* `[[اسم الملف]]` → رابط داخلي
* `#عنوان` → عنوان
* `- [ ]` → مهمة
* `![[اسم الصورة.png]]` → إدراج صورة

---

# 13) مثال عملي كامل

اكتب هذا داخل Note جديدة:

```markdown
# مشروع KiCad

## المهام
- [ ] إنهاء schematic
- [ ] مراجعة PCB
- [x] إنشاء مجلد المشروع

## ملفات مرتبطة
- [[Power Supply]]
- [[STM32 Notes]]

## وسوم
#kicad #pcb #electronics

## ملاحظة
هذا المشروع يحتاج مراجعة مسارات الطاقة.

> انتبه إلى عرض المسارات الخاصة بالتيار العالي
```

---

# 14) أهم نصيحة

لا تحاول حفظ كل شيء مرة واحدة.
ابدأ بهذه الأربعة فقط:

1. إنشاء ملف جديد
2. كتابة عناوين بـ `#`
3. عمل روابط بـ `[[ ]]`
4. عمل مهام بـ `- [ ]`

بعدها ستشعر أن Obsidian صار سهل جدًا.

لو تريد، أقدر أعمل لك بعد هذا مباشرة **ملخصًا صغيرًا جدًا على شكل ورقة غش Cheat Sheet** بالعربي تحفظ منه بسرعة.
